# 📍 구글 지도 저장함 카테고리별 재편 가이드

구글 지도(Google Maps)는 공식적으로 저장함(Saved Places) 목록 간의 일괄 이동 API를 제공하지 않기 때문에, 아래의 **2가지 방법 중 편리한 방법**을 선택하여 재편할 수 있습니다.

---

## 🚀 방법 1. 브라우저 콘솔 스크립트로 구글 지도 직접 재편하기 (추천: 프로그램 설치 없이 즉시 실행)

기존 구글 지도 계정 내에서 여행 목록(스페인, 대만 등)에 흩어진 장소들을 **[식당 및 카페], [숙박], [유적지 및 관광지]** 등의 목록으로 자동 분류·추가하는 방식입니다.

### 📌 진행 순서
1. **대상 목록 생성**:
   - PC 브라우저(네이버 웨일, 크롬 등)에서 [구글 지도(Google Maps)](https://www.google.com/maps)에 접속하여 로그인합니다.
   - 좌측 메뉴 `[저장됨]` -> `[+ 새 목록]`을 눌러 이동할 카테고리 목록들을 만듭니다:
     - `식당 및 카페`
     - `숙박`
     - `유적지 및 관광지`
     - `쇼핑`
     - `자연 및 공원`
     - `기타`
2. **정리할 여행 목록 열기**:
   - 저장됨 탭에서 정리할 여행 목록(예: `2026 스페인 포르토 여행`)을 클릭해 목록 상세 화면으로 진입합니다.
3. **콘솔 창 열기**:
   - 키보드의 `F12` (또는 `Cmd + Option + I`)를 눌러 개발자 도구를 열고 상단 **`[Console]`** 탭을 선택합니다.
4. **스크립트 실행**:
   - 프로젝트 폴더의 [`google_maps_console_organizer.js`](file:///Users/mac/orca/projects/구글 지도 저장함 개편/google_maps_console_organizer.js) 내용 전체를 복사하여 콘솔창에 붙여넣고 `Enter`를 누릅니다.
   - 스크립트가 각 장소의 태그(음식점, 호텔, 성당, 박물관 등)를 자동으로 감지하여 해당하는 카테고리 목록에 체크/저장합니다.
5. 다른 여행 목록(예: `2026 대만`)도 동일하게 2~4번을 반복하면 모든 여행지의 장소들이 카테고리별로 통합 재편됩니다.

## 📦 방법 2. 구글 테이크아웃(Takeout) 데이터 추출 + 내 지도(My Maps) 레이어 구성 (추천: 대량 정리 & 시각화 최적)

구글에서 공식 지원하는 데이터 백업 기능인 **Google Takeout**을 사용하여 저장된 장소 목록을 한 번에 다운로드받고, 카테고리별로 자동 분류하여 **구글 내 지도(My Maps)**에 깔끔하게 import하는 방법입니다.

### 📌 장점
- 모바일 구글 지도 앱의 `[저장됨] -> [지도]` 탭에서 **식당(빨강 핀), 숙박(파랑 핀), 유적지(노랑 핀)**처럼 색깔과 아이콘이 다르게 한눈에 표시되어 여행이나 평상시 관리에 훨씬 편리합니다.

### 📌 진행 순서
1. [Google 테이크아웃(Takeout)](https://takeout.google.com)에 접속합니다.
2. 상단의 **'모두 선택 해제'**를 누른 뒤, 스크롤을 내려 **`[저장됨(Saved)]`** 항목만 체크합니다.
3. '다음 단계' -> '내보내기 생성'을 누르고 다운로드 링크가 나오면 zip 파일을 다운로드합니다.
4. 다운로드받은 파일을 본 프로젝트 디렉토리(`구글 지도 저장함 개편`)에 옮겨놓습니다.
5. 터미널에서 아래 명령을 실행합니다:
   ```bash
   python3 takeout_organizer.py [다운로드받은_파일명.zip]
   ```
6. `reorganized_output/` 폴더에 `분류_식당_카페.csv`, `분류_숙박.csv`, `분류_유적지_관광지.csv` 등이 자동 생성됩니다.
7. [구글 내 지도(My Maps)](https://mymaps.google.com)에서 '새 지도 만들기'를 누르고, 각 레이어에 해당 CSV 파일을 드래그하여 업로드하면 완료됩니다!
