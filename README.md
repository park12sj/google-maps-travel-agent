# 📍 구글 지도 저장함 관리 & 맞춤 여행 플래너 AI 에이전트 시스템

구글 지도에 흩어진 여행지 장소들을 체계적으로 관리하고, 유튜브/블로그 링크 속 장소를 자동으로 수집하며, 사용자의 여행 취향을 학습하여 최적의 맞춤 일정을 생성해주는 지능형 에이전트 시스템입니다.

---

## 🌟 주요 기능 (3대 에이전트 시스템)

### 1. 🔗 링크 기반 장소 수집 및 통합 관리 (Place Ingestion Agent)
- 유튜브 영상, 네이버/티스토리 블로그, **인스타그램(릴스, 피드 게시물, 캐러셀 카드뉴스)** 링크를 입력하면 본문 및 캡션 속 장소를 자동 추출합니다.
- **6대 카테고리**(식당 및 카페, 숙박, 유적지 및 관광지, 자연 및 공원, 쇼핑 및 시장, 기타)로 자동 분류합니다.
- 마스터 DB(`data/places/places_master.json`)에 영구 저장됨과 동시에, **여행 플래닝에 최적화된 지역별 전용 폴더(`data/mymaps/<지역>/`)에 카테고리별 CSV 및 단일 레이어용 전체 CSV로 자동 동기화**됩니다.
- 전 세계 통합본도 `data/mymaps/_전체_통합/`에 함께 유지되므로, 여행지별 독립 지도 제작과 전체 통합 조회가 모두 가능합니다.

### 2. ✈️ 숙소 기반 맞춤 여행 일정 자동 계획 (Itinerary Planner Agent)
- 숙소 정보(이름, 위치 또는 링크)와 여행 일수를 제시하면 구글 지도 저장함의 장소들을 최적 배치하여 일정을 작성합니다.
- 사용자의 여행 스타일(출발 시간, 권장 장소 수, 점심 맛집, 오후 필수 카페 타임, 디너)을 100% 반영합니다.
- **🗺️ 날짜별 하루 전체 연결 경로(Google Directions) 링크 제공**: 숙소 ➔ 오전 명소 ➔ 점심 ➔ 카페 ➔ 저녁 ➔ 숙소로 이어지는 모든 장소를 클릭 한 번에 구글 지도 길찾기 모드로 열어볼 수 있는 다중 경유지 경로 링크를 생성합니다.
- 동선이 꼬이지 않도록 같은 권역끼리 묶고, 모든 장소에 바로 연결되는 개별 지도 링크도 함께 제공합니다.

### 3. 🧠 피드백 기반 여행 취향 학습 및 에이전트 동적 재구성 (Adaptive Feedback Agent)
- 일정에 대해 피드백을 주면(*"너무 빡빡해", "아침 11시에 시작해줘", "해산물은 빼줘", "도보 10분 이내로"*) 여행 취향 프로필(`config/user_travel_profile.json` 및 `.md`)을 즉시 재구성합니다.
- 한 번 학습된 취향은 영구 보존되어 다음 여행 일정 생성 시 자동으로 100% 적용됩니다.

## 🚀 사용 방법

### 💬 방법 A: Antigravity AI 어시스턴트 대화창에서 바로 사용 (가장 편리)
별도의 명령어 없이 대화창에서 자연어로 요청하시면 에이전트가 즉시 처리합니다:
- **장소 저장**: `"이 유튜브 영상에 나오는 장소들 추출해서 내지도에 저장해줘: https://youtu.be/..."`
- **일정 생성**: `"숙소는 바르셀로나 고딕 지구 호텔이고 3박 4일 일정 짜줘."`
- **취향 피드백**: `"스케줄이 너무 빡빡해. 아침은 11시 이후에 출발하고 해산물은 못 먹어."`

### 💻 방법 B: 터미널 CLI 명령어 사용
터미널에서 직접 도구를 실행할 수도 있습니다:

```bash
# 1. 링크(유튜브, 블로그, 인스타그램)에서 장소 추출 및 내지도 CSV 누적 저장
python3 cli.py add-link "https://www.instagram.com/reel/..." --region "도쿄"
python3 cli.py add-link "https://blog.naver.com/..." --region "후쿠오카"

# 2. 숙소 및 일수 기반 맞춤 여행 일정 생성
python3 cli.py plan --hotel "후쿠오카 하카타 호텔" --days 3 --region "일본 후쿠오카"

# 3. 여행 취향 피드백 입력 및 프로필 재구성
python3 cli.py feedback "아침잠이 많아 11시 시작하고, 해산물은 빼줘"

# 4. 현재 여행 취향 프로필 확인
python3 cli.py profile

# 5. 구글 내 지도(My Maps) 카테고리별 통합 CSV 현황 확인 및 재동기화
python3 cli.py mymaps

# 6. 저장된 장소 목록 검색 및 조회
python3 cli.py list --category "식당 및 카페"
```

## 🗺️ 구글 내 지도(My Maps)에 불러오는 방법
1. [구글 내 지도(Google My Maps)](https://mymaps.google.com)에 접속하여 **'새 지도 만들기'**를 클릭합니다. (예: 지도 제목을 "2026 후쿠오카 여행" 등으로 입력)
2. 각 레이어(예: 식당/카페, 숙박, 유적지 등)에 해당 지역 폴더(`data/mymaps/일본 후쿠오카/`)의 `내지도_*.csv` 파일을 드래그하여 업로드합니다.
   - 단일 레이어로 한 번에 올리고 싶다면 `<지역>_전체.csv`를 업로드하시면 됩니다.
3. 마커 위치 열은 **`검색위치`**, 마커 제목 열은 **`장소 이름`**을 지정합니다.
4. 모바일 구글 지도 앱의 `[저장됨] -> [지도]`에서 색상/아이콘별로 저장된 모든 장소를 한눈에 보며 여행할 수 있습니다.
