# 룰: 맞춤 여행 일정 자동 계획 (Itinerary Planner Rule)

## 📌 목적
숙소 정보(링크 또는 위치/이름)와 여행 일수(예: 2박 3일, 4일 등)가 주어지면, 구글 지도에 저장된 장소 데이터베이스(`data/places/places_master.json`)와 사용자의 최신 여행 스타일 프로필(`config/user_travel_profile.json`)을 결합하여 날짜별·시간대별 최적 동선의 여행 계획을 수립합니다.

## 🎯 트리거 조건
- 숙소 링크/명칭과 여행 일수가 포함된 대화 (예: "바르셀로나 고딕 지구 호텔 3박 4일 일정 짜줘", "숙소는 여기(링크)인데 4일 동안 일정 추천해줘")
- "저장해둔 장소들로 일정 만들어줘", "여행 계획 세워줘" 등의 요청

## 🛠️ 수행 절차
1. **사용자 취향 프로필 필수 확인**:
   - `config/user_travel_profile.json` (또는 `config/user_travel_profile.md`)의 최신 설정을 반드시 읽습니다.
   - **확인 항목**:
     - `pace`: 템포 (여유로움 / 보통 / 알참)
     - `max_places_per_day`: 하루 방문할 최대 장소 개수
     - `morning_start_time`: 하루 시작 시간 (예: 10:00 또는 11:00)
     - `evening_return_time`: 복귀 시간
     - `must_include_cafe_break`: 카페 휴식 타임 필수 여부
     - `disliked_foods`: 제외해야 하는 음식 (예: 해산물 등)
     - `max_continuous_walking_minutes`: 도보 한계 (예: 10분 이내)
2. **저장된 장소 검색 및 필터링**:
   - 숙소가 위치한 도시/지역과 일치하는 장소들을 `data/places/places_master.json`에서 추출합니다.
   - 식당/카페, 유적지/관광지, 자연/공원, 쇼핑/시장으로 분류하고 기피 항목은 배제합니다.
3. **일정 계획 생성 로직**:
   - `python3 cli.py plan --hotel "<숙소>" --days <일수> [--region "<도시>"]` 명령을 실행하거나 내부 엔진을 통해 계획을 작성합니다.
   - 숙소 출발 ➔ 오전 명소 ➔ 점심 식사(저장 식당) ➔ 오후 카페 휴식 ➔ 오후 관광/쇼핑 ➔ 저녁 식사(타파스/로컬 디너) ➔ 야경/숙소 복귀 순으로 구성합니다.
   - 동선이 꼬이지 않도록 같은 권역 내의 장소들을 하루 일정으로 묶습니다.
4. **결과 문서 저장 및 안내**:
   - 작성된 일정표를 `data/itineraries/` 디렉토리에 마크다운으로 저장합니다.
   - 사용자에게 시간표, 각 장소의 특징/팁, [📍 구글 지도 링크](file:///)가 포함된 깔끔한 마크다운 표로 답변합니다.
   - 피드백을 주면 취향 프로필이 자동 재학습된다는 안내 문구를 덧붙입니다.
